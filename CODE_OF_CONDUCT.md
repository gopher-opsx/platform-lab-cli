# Code of Conduct

## Our Standard

Platform Lab CLI is an open-source learning project.

We want discussions, issues, pull requests, and other project interactions to remain professional, respectful, and constructive.

Contributors and community members are expected to:

- Treat others with respect
- Focus criticism on ideas, code, and technical decisions
- Provide constructive feedback
- Be patient with learners and new contributors
- Respect different levels of experience and technical background
- Help maintain a welcoming learning environment

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or intimidation
- Personal attacks
- Discriminatory or offensive comments
- Deliberately disruptive behavior
- Publishing another person's private information without permission
- Abusive or hostile communication

## Technical Discussions

Disagreement is normal in engineering.

When discussing technical decisions:

- Explain the reasoning behind your position
- Provide evidence when possible
- Avoid attacking the person making the proposal
- Assume good intent
- Keep discussions focused on improving the project

## Enforcement

Project maintainers may edit, remove, or reject comments, issues, pull requests, or contributions that violate this Code of Conduct.

Repeated or serious violations may result in temporary or permanent exclusion from project participation.

## Scope

This Code of Conduct applies to all official Platform Lab CLI project spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Code reviews
- Other project-managed communication channels
